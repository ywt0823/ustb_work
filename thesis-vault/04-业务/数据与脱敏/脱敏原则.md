# 脱敏原则 v1（2026-08-08）

> 未脱敏原始对话 **禁止** 写入本 vault、Git、网盘公开目录。

## 1. 必须去除或不可逆映射

| 字段类 | 处理 |
|--------|------|
| 姓名 / 昵称 | 替换为 `U_###` / `HR_###` |
| 手机 / 座机 | 删除或 `PHONE_HASH` |
| 邮箱 / 微信号 / QQ | 删除 |
| 身份证 / 银行卡 | 删除 |
| 具体公司名 / 品牌 / 门店地址 | 代号 `COMP_##` / 泛化到行业 |
| 精确薪资、HC、提成点 | 分桶（如 8–10k）或删除 |
| 可反推个人的稀有组合 | 打散或删除（如「唯一技能+唯一城市+年龄」） |

## 2. 可保留（研究需要）

- 对话轮次结构、角色（求职者/系统）
- 意图标签、是否切换意图
- 槽位**类型**与泛化值（城市→一线/新一线；年龄→区间）
- 动作标签：EXECUTE / CLARIFY / ABSTAIN（可由规则+抽检得到）
- 证据文档类型与匿名 doc_id；是否命中 RAG
- 工具调用成败（不含原始业务回包隐私字段）
- 会话时长、轮数等聚合特征

## 3. 处理流程

1. 导出仅限授权字段 → 2. 脚本脱敏 → 3. 人工抽检 5% → 4. 生成 `manifest.json`（样本数、字段、日期）→ 5. 仅脱敏包可离线使用

## 4. 论文公开边界

| 可公开 | 不可公开 |
|--------|----------|
| 聚合指标、曲线、消融表 | 原始对话日志 |
| 改写后的示意案例（已再脱敏） | 未改写的真实用户原话若含 PII |
| 算法伪代码与阈值标定方法 | 内部模型权重 / 未授权 API Key |

## 5. 版本

- 变更需同步更新数据授权申请附件
