# 选题锁定

## 建议题目

**基于意图信念更新的风险敏感多轮对话决策算法及其在招聘场景的验证**

备选更硬表述：

> 面向部分可观测对话意图的序贯决策算法：信念估计、澄清动作选择与证据约束解码

## 科学问题

在招聘多轮对话中，用户意图部分可观测、误答/幻觉代价高。如何在仅使用 LLM API 的条件下，设计可计算的信念更新与风险敏感决策算法，在回答 / 澄清 / 拒答之间做最优（近似最优）选择，并保证事实性输出受证据约束？

## 非目标

- 不提出新的 Transformer/GPT 基座架构
- 不以旅游路书为主场景
- 不做纯业务系统集成作为“创新点”

## 预期贡献（算法向）

1. 招聘多轮对话的不确定感知形式化（信念状态）
2. 风险敏感澄清 / 应答动作选择准则
3. 证据约束下的幻觉抑制机制（与决策耦合，而非后处理点缀）

## 见导师口径

> 不是做招聘 GPT 应用，而是提出序贯决策算法；大模型 API 仅作语义推理模块。创新在信念更新与决策/约束机制；在脱敏招聘对话上相对 CICC / UoT / Naive RAG 等强基线验证。
