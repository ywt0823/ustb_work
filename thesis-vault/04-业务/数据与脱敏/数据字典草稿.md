# 数据字典草稿 v0

> 对应现有 Agent 协议字段 → 算法变量映射。授权后按真实表结构修订。

## 会话级

| 字段 | 类型 | 说明 | 算法用途 |
|------|------|------|----------|
| session_id | string | 匿名会话 ID | 主键 |
| turn_id | int | 轮次 | 序贯索引 |
| role | enum | user / agent | 输入过滤 |
| utterance | text | 脱敏后文本 | 观测 |
| task_type | enum | match / lead / qa | 多目标代价选择 |

## 中控输出（可直接或近似得到）

| 字段 | 类型 | 算法变量 |
|------|------|----------|
| intent | string | 硬标签基线 |
| intent_probs / belief | map | \(b_t\) |
| confidence | float | 不确定度输入 |
| slots | object | 槽位 |
| slot_uncertainty | float/map | \(z_t\) |
| evidence_score | float | \(e_t\)（可由 RAG 命中+重排分构造） |
| evidence_docs | list[id] | 证据集合 \(\mathcal{E}_t\) |
| action_gold | enum | EXECUTE/CLARIFY/ABSTAIN |
| action_pred | enum | 模型输出 |
| cost_tag | enum | 错误类型标签（可选） |

## 标签规范（最小开题集）

每条样本至少具备：

1. `utterance`（脱敏）  
2. `belief` 或 `intent+confidence`  
3. `evidence_score`（可规则近似）  
4. `action_gold`（人工或弱监督）  
5. `task_type`

## 规模目标（开题最小）

- 精标案例：10–20 条三动作正反例（含「96的」类）  
- 弱标评测：≥200 轮（若授权）或合成替代
