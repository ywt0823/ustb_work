# 算法理论深化方案：把 EG-RSD 做成「底层算法研究」

> 触发：导师明确要求 **底层算法研究**——读透已有算法 → 结合业务 → 给出算法创新 → 回到业务数据验证。  
> 结论：方向不变，但**理论根必须换成经典决策理论**，不能停在「工程决策层」的叙事。

## 1. 问题：原表述为什么不够「底层」

| 原表述 | 会被怎么看 |
|--------|------------|
| 「在 LLM 外面加一层决策」 | 系统/中间件，不是算法 |
| 「把信念+澄清+证据结合」 | 模块组合 |
| 「风险函数由业务代价定」 | 参数工程 |

缺的是：**一个经典算法问题的形式归属**，以及**相对该经典结果的可证明推广**。

## 2. 解法：接上「带拒答的最优决策」这条经典理论线

本课题真正归属的经典问题是 **Reject-Option Classification / Selective Prediction**：

- **Chow (1970)**：给出带拒答的最优决策规则——当最大后验概率低于阈值时拒答，并推导 error–reject 权衡关系。这是「模型该不该回答」的理论源头。
- **Franc, Průša & Voráček (JMLR 2023)**：证明 cost-based / bounded-improvement / bounded-abstention 三种拒答模型导出同一最优策略（Bayes 分类器 + 随机化 Bayes 选择函数），并给出黑盒模型下学习「proper uncertainty score」的算法与一致性证明。
- **El-Yaniv & Wiener (JMLR 2010)**：selective classification 的风险–覆盖率（RC）理论边界。
- **Hendrickx et al. (MLJ 2024)**：learning with rejection 综述，区分 ambiguity rejection 与 novelty rejection。

**这条线正是本课题的底层归属**：招聘对话里的「拒答/转人工」就是 reject option；「澄清」是经典理论里没有的第三个动作；「证据充分度」是经典理论里没有的可行性约束。

## 3. 本课题的算法创新（相对经典结果的三点推广）

经典 Chow 规则处理的是：**单步、二元决策（预测 or 拒答）、仅依赖后验概率、代价对称或单一拒答代价**。

本课题拟推广为：

| 维度 | 经典 | 本课题 |
|------|------|--------|
| 时序 | 单步 | 多轮序贯（信念随对话更新） |
| 动作 | 预测 / 拒答 | 回答 / **澄清** / 拒答 |
| 依据 | 后验概率 \(\max_z b(z)\) | 后验 **+ 证据充分度 \(s_t\)** |
| 约束 | 无 | **证据可行域** \(\mathcal{A}_{\text{feasible}}(\mathcal{E}_t)\) |
| 代价 | 单一拒答代价 | 意图误判 / 事实幻觉 / 澄清 / 转人工 **不对称代价** |
| 保证 | error–reject 曲线 | 拟给出 **分布无关的幻觉风险上界**（共形风险控制） |

**一句话创新表述（对导师）：**

> 本研究将 Chow 的最优拒答规则推广到「证据约束下的多轮三动作决策」：在动作集中显式引入澄清与证据可行性，推导新的最优决策边界，并证明经典拒答规则是本框架在无澄清、证据恒充分条件下的特例。

这就从「加一层」变成了「推广一个经典最优性结果」。

## 4. 三层理论骨架

### 层一：决策层（核心贡献）

在信念 \(b_t\) 与证据充分度 \(s_t\) 下，最小化期望风险：

\[
a_t^\star=\arg\min_{a\in\mathcal{A}_{\text{feasible}}(\mathcal{E}_t)}
\mathbb{E}_{z\sim b_t}\big[R(a,z)\big]
\]

其中回答动作在 \(s_t<\tau\) 且问题为事实型时不可行。

**要推导的是决策边界的解析形式**，而不是写个 if-else。

### 层二：估计层（不确定度必须可信）

- 意图后验用共形预测构造预测集，获得可交换性下的覆盖保证；
- 证据充分度需校准（ECE / 可靠性图）；
- 黑盒 API 下按 Franc 等的思路学习 **proper uncertainty score**，而不是直接信 LLM 自评分数。

### 层三：保证层（把阈值变成有保证的量）

用 **Conformal Risk Control（Angelopoulos et al., ICLR 2024）** 标定证据阈值 \(\tau\)，使得：

\[
\mathbb{E}\big[\ell_{\text{hallucination}}\big]\le\alpha
\]

即：**在给定校准集上选 \(\tau\)，可给出幻觉损失期望不超过 \(\alpha\) 的有限样本保证**。

> 重要提醒：近期已有工作指出 CRC 在结构化生成上存在可行性下界——当基础错误率 \(\mu>\alpha\) 时，任何分布无关方法都必须弃权至少 \((\mu-\alpha)/(1-\alpha)\) 比例。这对本课题是**加分点**：可以直接讨论「招聘场景要达到目标幻觉率，最少需要多少拒答/澄清」，这本身就是一个有理论味的结论。

## 5. 拟证明的命题（开题写「拟证明」，不能写「已证明」）

| # | 命题 | 难度 | 价值 |
|---|------|------|------|
| P1 | **门控安全性**：若 \(s_t<\tau\) 且无据回答代价高于澄清与拒答代价，则最优动作不含无据回答 | 低 | 必做，直接支撑创新点 |
| P2 | **退化定理**：无澄清动作、\(s_t\equiv1\)、代价对称时，最优策略退化为 Chow 规则 | 中 | 最有说服力，证明是「推广」而非「另起炉灶」 |
| P3 | **单调性**：幻觉代价上升或 \(s_t\) 下降时，回答区域不扩大 | 中 | 说明决策边界行为合理 |
| P4 | **风险–澄清权衡曲线**：类比 error–reject 曲线，刻画幻觉率与平均澄清轮数的权衡 | 中高 | 可作为实验主图，理论与实验对齐 |
| P5（可选） | 用 CRC 给出满足目标幻觉率所需的最小弃权/澄清比例下界 | 高 | 亮点，但可放"展望" |

**建议开题承诺 P1 + P2，力争 P3/P4。** P5 只写为可能方向。

## 7. 与业务数据的回归（导师要求的最后一环）

理论不能悬空，必须用招聘数据把参数与验证接回来：

| 理论量 | 业务来源 |
|--------|----------|
| 代价 \(c_i,c_f,c_q,c_h\) | 历史错误频率 + 业务专家成对排序 + 敏感性分析 |
| 意图先验与转移 \(T\) | 脱敏历史多轮会话统计 |
| 校准集 | 脱敏标注样本（意图、证据支持、是否应澄清） |
| 目标风险 \(\alpha\) | 业务可接受的高风险事实错误率 |
| 验证 | 离线回放 → 风险–澄清权衡曲线 → 影子模式 |

**关键实验图（建议做成论文主图）：**  
横轴平均澄清/拒答比例，纵轴幻觉率或加权风险，把 EG-RSD 与 Chow 式固定阈值、纯 IG 澄清、Naive RAG 画在同一张 RC 型曲线上。这张图同时体现「理论推广」和「业务收益」。

## 8. 查重红线（必须先做）

在把 P2 写进创新点前，必须专项检索确认没有同构工作：

```text
sequential reject option classification
reject option with query / active learning with abstention
selective prediction with clarification
conformal abstention dialogue
evidence-conditioned abstention LLM
risk-sensitive dialogue policy LLM
```

若发现「拒答 + 提问」已有完整理论工作 → 退守 **证据可行域 + 招聘不对称代价** 这两点差异，并在综述中显式区分。

## 9. 开题创新点（按底层算法口径重写）

1. **（主）证据约束下的多轮三动作最优决策规则**：将经典最优拒答规则推广到含澄清动作与证据可行域的序贯场景，推导决策边界并给出退化关系。
2. **（辅）黑盒 LLM 下的可信不确定度与阈值标定方法**：结合共形预测/共形风险控制，为证据阈值提供分布无关保证，并在招聘脱敏数据上完成风险–澄清权衡的实证刻画。
