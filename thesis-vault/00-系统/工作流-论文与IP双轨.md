# 工作流：论文与 IP 双轨

每次与 AI 协作，默认跑两条轨道，避免「聊完就散」。

## Track A · 论文

```text
提出问题 → 查文献/算法 → 形成决策 → 写入01/03/05 → 产出可引用文本
```

检查清单：

- [ ] 是否推进了选题/方法/实验/写作中的至少一项？
- [ ] 是否有可双链回论文笔记的结论？
- [ ] 是否更新了对应 MOC？

## Track B · 产品 IP（《如何利用 AI 完成研究生论文》）

```text
记录会话 → 提炼模式 → 沉淀提示词 → 写入案例/方法论 → 形成可对外内容
```

检查清单：

- [ ] `SES-` 会话是否写完？
- [ ] 是否抽出「可复用协作模式」（例如：约束收敛、文献雷达、算法 sharpen）？
- [ ] 是否有一句「如果做成产品功能，它是什么」？

## 双轨同步模板句（会话末尾必填）

- **论文收获**：……
- **IP 收获**：……
- **下次输入**：……
