# SES · 研究思路与业务算法闭环

## 用户问题

> 当前你的研究思路是什么？算法革新的方向是什么？如何通过已有业务叠加算法的迭代？

## 回答结论

1. 研究对象不是招聘 GPT 应用，而是**证据门控的风险敏感多轮对话决策算法**；
2. UB-CEG 是总体框架，论文主创新收束为 EG-RSD：在统一风险下选择回答、澄清或拒答；
3. 算法利用意图信念、证据充分度和业务不对称代价动态改变决策边界；
4. 通过旁路层低侵入接入现有业务，用脱敏日志估计意图转移、校准不确定度、定义风险并持续离线/影子迭代；
5. 路线按 V0 日志基线 → V1 信念校准 → V2 证据门控 → V3 统一风险决策 → V4 前瞻澄清推进；
6. 创新尚需进一步系统查重，不能提前宣称“首次”。
