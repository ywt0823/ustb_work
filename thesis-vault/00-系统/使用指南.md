# 使用指南

## 第一次打开

1. 安装 [Obsidian](https://obsidian.md)
2. Open folder as vault → 选择本仓库中的 `thesis-vault/`
3. 从 [[00-系统/首页]] 进入

## 日常三步（强制习惯）

1. **开聊前**：在 Daily 或对应 MOC 写清今天目标（1–3 条）
2. **聊完后**：用模板新建一篇 [[Templates/T-AI会话记录|AI 会话记录]]，写入 `06-AI协作日志/会话记录/`
3. **有拍板**：立刻补一篇 [[Templates/T-决策记录|决策记录]]，并反向链接到论文相关笔记

> 产品 IP 的核心原料是「完整协作过程」。漏记一次，就少一块可复用案例。

## 写不同类型笔记时用哪个模板

| 你要记什么 | 模板 | 落点目录 |
|------------|------|----------|
| 与 AI 的一次完整交互 | `T-AI会话记录` | `06-AI协作日志/会话记录/` |
| 题目/方法/实验拍板 | `T-决策记录` | `06-AI协作日志/决策记录/` |
| 一篇论文精读 | `T-文献笔记` | `02-文献/核心论文/` |
| 一个算法条目 | `T-算法卡片` | `03-算法/...` |
| 可复用 Prompt | `T-提示词资产` | `06-AI协作日志/提示词资产/` |
| 产品洞察 | `T-产品洞察` | `07-产品IP/案例素材/` |
| 当日碎片 | `T-每日笔记` | `Daily/` |

## 质量门槛（防库腐烂）

- 每篇至少有：`status`、至少 1 个双链、至少 1 个标签
- 会话记录必须含：**目标 / 关键对话摘要 / 产出物链接 / 下一步**
- 禁止只贴长对话无提炼；原文可折叠放附录

## 推荐插件（可选，非必须）

- Dataview：按 status/tag 自动列表
- Calendar：配合 Daily
- Excalidraw / Canvas：技术路线图
- Git：与仓库同步（若本机使用）
