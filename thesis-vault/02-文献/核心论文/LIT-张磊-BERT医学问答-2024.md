# LIT · 张磊（华中科技大学 · 软工专硕 · 2024）

## 书目

- 题名：基于 BERT 的医学智能问答关键算法的研究
- 作者：张磊；导师：苏曙光；学校：华中科技大学
- 学位：工学硕士（专业型）；答辩：2024-07
- PDF：`208865f6-20d1-430e-97d7-865c69539003.pdf`

## 一句话

典型的「垂直领域 + NLU 模块改进 + RAG/图谱系统验证」专硕论文；研究如何更准地识别实体/意图并检索生成答案，**不研究不确定时的动作决策**。

## 自述贡献（4 点）

1. **BERT+LSTM+CRF**：句子级语义 + 问句–属性相似度选属性  
2. **实体识别增强**：数据增强（替换/掩码/拼接）+ TF-IDF 对齐；三指标相似度（字重叠 / 余弦 / 编辑距离）均值过阈值匹配  
3. **意图识别**：对比规则 / 训练模型 / 提示工程，选 **34B + Prompt**（16 类意图，可多意图）  
4. **系统应用**：DiseaseKG + Neo4j + RAG + 大模型，落地卫健委科普馆医疗问答

## 流水线

用户查询 → 实体识别 → 意图识别 → 生成查询 → 知识图谱检索 → 大模型处理 → 回答生成

## 评价指标

NER / 分类：P、R、F1；系统侧为知识检索与问答效果展示。几乎不见风险—覆盖率、澄清轮次、错误执行代价。
