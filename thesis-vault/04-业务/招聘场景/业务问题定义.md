# 业务问题定义（招聘）

## 场景

公司业务为招聘相关；对话系统服务求职者/HR 多轮咨询（岗位、流程、要求等）。

## 痛点（用户原述）

1. 对话不准
2. 衔接不流畅
3. 意图识别存在幻觉（假自信、答非所问、事实编造）

## 约束

- 数据量丰富，必须脱敏后方可入实验/论文
- 推理侧仅能调用 API
- 需要可量化业务/任务指标回归验证

## 映射到算法问题

| 业务痛点 | 算法对应 |
|----------|----------|
| 意图幻觉/不准 | 信念分布而非硬分类；校准与共形集 |
| 衔接不流畅 | 多轮状态维持 + 澄清策略 |
| 事实乱讲 | 证据门控与拒答 |
