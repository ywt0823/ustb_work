# 命名规范

## 文件名

```text
[类型前缀-]主题-可选副标题.md
```

| 前缀 | 含义 | 示例 |
|------|------|------|
| `MOC-` | 内容地图 | `MOC-论文总览.md` |
| `DEC-` | 决策 | `DEC-2026-07-29-主攻招聘对话算法.md` |
| `SES-` | AI 会话 | `SES-2026-07-29-选题收敛.md` |
| `LIT-` | 文献 | `LIT-CICC-2024.md` |
| `ALG-` | 算法 | `ALG-UB-CEG.md` |
| `EXP-` | 实验 | `EXP-主实验协议-v0.md` |
| `IP-` | 产品 | `IP-内容矩阵-v0.md` |
| `T-` | 模板 | `T-文献笔记.md` |

日期统一：`YYYY-MM-DD`。

## 标题与双链

- 笔记一级标题 = 可读中文名
- 双链优先用文件名（Obsidian 默认识别）
- 概念首次出现时创建概念卡或链到已有卡

## Frontmatter 最小集

```yaml
---
title: 
type: # moc | literature | algorithm | decision | session | experiment | product | note
status: # seed | drafting | review | stable | archived
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
sources: []  # 可选：arxiv / url / 会话 id
---
```

## 状态流转

`seed` → `drafting` → `review` → `stable` →（过时）`archived` 并移入或链到 `09-归档`
