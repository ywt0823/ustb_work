## 2. 文献计划：20 篇有效精读 + 40 篇入库

### 2.1 “有效论文”判定（读完才算数）

每篇必须在 `02-文献/核心论文/` 或专题笔记中留下：

1. 一句话贡献  
2. 输入 / 输出 / 算法步骤  
3. 数据与指标  
4. 与本课题关系（可借鉴 / 基线 / 差异）  
5. 局限与可攻击点  

只看摘要、无笔记、无差异陈述 → **不算有效**。

### 2.2 20 篇精读配额（建议结构）

| 批次 | 主题 | 篇数 | 截止 |
|------|------|------|------|

| B1 | 澄清 / 不确定 | 4 | 8/18 |
| B2 | 幻觉 / RAG / 证据约束 | 4 | 8/21 |
| B3 | POMDP / DST | 2 | 8/23 |
| B4 | 招聘 / 中文 / 任务型应用 | 4 | 8/28 |
| **合计精读** | | **20** | **8/28** |
| B5 | 补充浏览入库（不精读） | ≥20 | 9/3 |

## 4. 研究报告结构（与开题分工）

建议单独写《研究报告 / 文献总结》（约 0.6–1.0 万字），再压缩进开题：

1. 引言与问题界定  
2. 任务型对话与信念状态  
3. 不确定感知与澄清决策  
4. 幻觉、RAG 与证据约束  
5. 招聘/职业对话应用  
6. 相关工作对比表与研究缺口  
7. 本课题方法定位（EG-RSD）  
8. 初步可行性观察（可选，来自最小实验）  
9. 结论与开题研究内容映射  

开题报告则更短、更偏方案：目标、内容、路线、实验、进度。
