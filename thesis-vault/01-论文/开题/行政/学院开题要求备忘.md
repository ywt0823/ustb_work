# 学院/校级开题要求备忘（W1）

> 以下为**校级公开信息**汇总；学院（计算机/软工）细则、模板与开题日必须以最新通知与导师确认为准。

## 已核实的校级底线

| 项 | 要求 | 来源 |
|----|------|------|
| 硕士书面开题字数 | 一般 **0.5～1.0 万字** | 研究生培养相关规定公开摘录 |
| 文献 | 近 15～20 年相关文献阅读分析；硕士一般 **不少于 40 篇** | 同上 |
| 评审 | 硕士开题评审小组一般至少 **3 名**副教授以上或博士学位教师 | 同上 |
| 评审表 | 须**先在研究生信息管理系统提交**，再下载打印《研究生开题报告及文献总结评审表》 | [研究生院下载中心](https://gs.ustb.edu.cn/index.php/cms/item-view-id-1816.shtml) |
| 选题类型 | 学术型偏学术；专业型偏应用/工程技术背景 | 公开培养原则意见类文件 |
| 格式 | 参照学校学位论文模板与 GB 相关撰写规范 | 公开规定 |

## 仍需你本人向学院/导师确认（W1 未闭环）

- [ ] 软件工程学院是否有**独立开题模板**与页数/PPT 时长要求
- [ ] 本年级正式**开题日期**与系统提交截止日（计划按 **2026-09-10** 冲刺）
- [ ] 本人学位类型：**学术型 / 专业型**（影响创新表述权重）
- [ ] 开题与中期、答辩的最短间隔（部分学院有「不少于 6 个月」类规定，需核对是否适用于本院）
- [ ] 是否需要企业导师或数据使用证明

## 对本课题的执行含义

1. 文献策略不变：**20 精读 + ≥20 浏览入库 = 40+**  
2. 开题报告控制在 0.5–1.0 万字；研究报告可另册支撑文献总结  
3. 9 月初必须完成系统提交演练，避免只会写 Word 不会提系统  
4. 专业型可强调业务验证；若偏学术型，P1/P2 与拒答理论比重必须抬高
